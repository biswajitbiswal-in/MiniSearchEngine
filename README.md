# Mini Search Engine

A Python-based Mini Search Engine using an inverted index and TF-IDF + Cosine Similarity ranking, built with the Python standard library.

## Usage

Web UI (and `/api/search?q=...` JSON endpoint):
```bash
python main.py --web
```

Interactive CLI mode:
```bash
python main.py
```

Single query CLI mode:
```bash
python main.py "python data science"
```

Self-check:
```bash
python main.py --check
```
